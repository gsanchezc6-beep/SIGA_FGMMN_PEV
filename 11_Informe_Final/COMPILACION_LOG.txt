PRUEBA DEL GATEKEEPER G2 (clon limpio)
--------------------------------------------------------------------------
Se clono el repositorio en un directorio vacio, se borro el main.pdf
versionado y se ejecuto compilar.sh:

  git clone https://github.com/gsanchezc6-beep/SIGA_FGMMN_PEV.git
  rm 11_Informe_Final/main.pdf
  bash 11_Informe_Final/compilar.sh

Resultado: main.pdf regenerado sin errores desde el clon, con el mismo
numero de paginas que el versionado. El hash MD5 difiere de una corrida a
otra porque el PDF incorpora la marca de tiempo (/CreationDate, /ID); el
contenido paginado es identico.
